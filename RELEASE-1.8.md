# Anime World Generator 1.8 — Matching reaction artwork

- Redrew all 18 new reaction hosts to match the original Natsu, Lucy, Goku and Vegeta artwork.
- Matched expressive chibi proportions, bold outlines, saturated cel shading and navy/purple backgrounds.
- Corrected atlas cropping for solo and paired reactions on desktop and mobile.
- Updated app version, cache keys, Windows launcher and offline packages to 1.8.

The new cast now follows the original portraits' playful reaction style. Character identities, dialogue and gameplay rules are preserved. The revised atlas retains all 18 character indices, and measured row crops keep adjacent artwork outside each portrait.

## Downloads

- **EXE:** standalone Windows launcher containing the complete offline game.
- **Windows ZIP:** extract and run Anime World Generator 1.8.exe.
- **Browser ZIP:** extract the entire archive and open index.html; keep the files together.
- **SHA256.txt:** checksums for all three downloads.

The Windows launcher extracts to %LOCALAPPDATA%\AnimeWorldGenerator\1.8. Its browser saves are separate from earlier launcher folders. The launcher is unsigned, as in previous releases.

## Validation

Reaction, dialogue, interface and mobile checks pass, including all 36 hosts and 93 opponents. Desktop and phone-width previews were checked, including paired original/new portraits and all 18 atlas cells. The release build verifies all 49 embedded assets against source SHA-256 hashes.

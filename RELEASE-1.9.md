## Downloads

- EXE: standalone Windows launcher containing the complete offline game.
- Windows ZIP: extract and run Anime World Generator 1.9.exe.
- Browser ZIP: extract the entire archive and open index.html. Keep all files together.
- SHA256.txt: checksums for all three downloads.

The launcher extracts to %LOCALAPPDATA%\AnimeWorldGenerator\1.9. Saves in this folder are separate from earlier launcher folders. The launcher is unsigned, as in previous releases.
